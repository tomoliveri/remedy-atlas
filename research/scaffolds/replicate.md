## Rerun the computation

Use the merged, reviewed scripts from the task prerequisites. Verify the input and script checksums, rerun both locally using the recorded seeds, and compare the outputs. Record exact agreement or the stated tolerance, software versions and disagreements. Run a negative control or a held-out check. Submit the reproduction script, a small machine-readable comparison and the run receipt. A result can be reproducible and still leave the biological question unresolved.
